# agy-auth v0.2.0-rc.2

This pre-release fixes one-command installation from the private repository while retaining the
complete profile workflow introduced in `v0.2.0-rc.1`.

## Install

Authenticate GitHub CLI once:

```bash
gh auth login
```

Then install:

```bash
gh release download v0.2.0-rc.2 \
  --repo ensp1re/agy-auth \
  --pattern agy-auth-installer.sh \
  --output - | sh
```

The installer downloads the remaining private release assets through authenticated `gh`, verifies
the Linux archive with SHA-256, and installs to `~/.local/bin`.

## Supported contract

- Release target: `x86_64-unknown-linux-gnu`.
- Verified clients: Antigravity CLI `1.1.2` and `1.1.3`.
- Environment: Linux SSH/headless file-backed authentication.

The profile contract is reverse engineered and is not supported by Google. Other platforms and
client versions fail closed.

## Included workflow

- Official-client delegated account enrollment.
- Direct capture of the current official account.
- Atomic default-account switching without launching `agy`.
- Interactive account selector with masked identities and last activity.
- Isolated one-off execution and interrupted-import recovery.

## Verification

- Complete local gate passed with 66 automated tests.
- Release archive, SBOM, installer, and checksum manifest verified.
- Installer passed local artifact installation and authenticated private GitHub release installation.
- Hosted CI was not used because the GitHub Actions usage limit is exhausted.
