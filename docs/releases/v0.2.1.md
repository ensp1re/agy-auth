# agy-auth v0.2.1

This stable release delivers the complete local profile workflow for the verified Linux contract
and keeps Windows available as a build-verified, mutation-gated target.

## Install

```bash
curl --proto '=https' --tlsv1.2 -fsSL \
  https://github.com/ensp1re/agy-auth/releases/download/v0.2.1/agy-auth-installer.sh |
  sh
```

The installer verifies the Linux archive with SHA-256 and installs `agy-auth` to
`~/.local/bin` by default.

## Supported contract

- Release target: `x86_64-unknown-linux-gnu`.
- Verified clients: Antigravity CLI `1.1.2` and `1.1.3`.
- Environment: Linux SSH/headless file-backed authentication.
- Windows builds and diagnostics compile in GitHub Actions CI; account mutation remains disabled.

The local profile contract is reverse engineered and is not supported by Google. Unknown client
versions and unverified storage modes fail closed.

## Included workflow

- Official-client delegated account enrollment.
- Direct capture of the current official account.
- Atomic default-account switching without launching `agy`.
- Interactive account selector with masked identities and last activity.
- Isolated one-off execution and interrupted-import recovery.

## Verification

- Complete local gate passed with 66 automated tests.
- Linux and Windows GitHub Actions CI passed.
- Dependency policy, compatibility, release metadata, secret scan, and harness validation passed.
- Release archive, SBOM, installer, and SHA-256 checksum manifest were generated from clean main.
