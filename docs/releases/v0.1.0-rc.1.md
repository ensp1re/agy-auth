# agy-auth v0.1.0-rc.1

This is the first MIT-licensed diagnostics-only release candidate for Linux x86_64.

## What is available

- `agy-auth doctor` human-readable diagnostics;
- `agy-auth --json doctor` schema-versioned diagnostics;
- safe `agy` executable discovery and bounded version probing;
- project-owned non-secret registry health checks;
- data-root ownership, permission, type, and recovery-marker checks;
- embedded tool version, source revision, and compilation target.

## What is not available

Profile switching is unsupported and authentication-state mutation is disabled. This release does
not provide `add`, `use`, or profile `exec`, and it never accesses Antigravity credentials, keyrings,
OAuth flows, model backends, or quota data.

## Supported evidence

- Release target: `x86_64-unknown-linux-gnu`.
- Observed official client: Antigravity CLI `1.1.2` via `--version` only.
- Hosted CI: deferred because the GitHub account workflow usage limit was reached.
- Untested: macOS, Windows, Linux ARM64, and other `agy` versions.

## Verify and install

```bash
sha256sum -c agy-auth-0.1.0-rc.1-x86_64-unknown-linux-gnu.sha256
tar -xzf agy-auth-0.1.0-rc.1-x86_64-unknown-linux-gnu.tar.gz
cd agy-auth-0.1.0-rc.1-x86_64-unknown-linux-gnu
install -d -m 0700 "$HOME/.local/bin"
install -m 0755 agy-auth "$HOME/.local/bin/agy-auth"
agy-auth doctor --client "$HOME/.local/bin/agy"
```

Removing `$HOME/.local/bin/agy-auth` uninstalls the binary and intentionally preserves project data.
