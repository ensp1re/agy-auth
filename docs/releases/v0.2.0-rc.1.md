# agy-auth v0.2.0-rc.1

This pre-release promotes the verified Linux profile workflow from diagnostics-only research to a
usable local account manager for Google Antigravity CLI.

## Highlights

- Save the account currently logged into the official `agy` home with `agy-auth add`.
- Enroll additional accounts through official `agy` with `agy-auth login`.
- Switch the account used by future plain `agy` launches without opening the client.
- Browse accounts through a terminal-safe interactive selector.
- Show profile name, masked account hint, client version, selected state, and last activity.
- Recover interrupted imports and retain refresh-token rotation.
- Install the prebuilt Linux binary with a checksum-verifying installer.

## Supported contract

- Release target: `x86_64-unknown-linux-gnu`.
- Verified clients: Antigravity CLI `1.1.2` and `1.1.3`.
- Environment: Linux SSH/headless file-backed authentication.

The profile contract is reverse engineered and is not supported by Google. Desktop keyrings, macOS,
Windows, Linux ARM64, and other `agy` versions remain unsupported for authentication-state mutation.
`agy-auth doctor` fails closed when the installed combination is not verified.

## Install

One-command installation:

```bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/ensp1re/agy-auth/releases/download/v0.2.0-rc.1/agy-auth-installer.sh | sh
```

For review-before-execution:

```bash
curl --proto '=https' --tlsv1.2 -fLO \
  https://github.com/ensp1re/agy-auth/releases/download/v0.2.0-rc.1/agy-auth-installer.sh
less agy-auth-installer.sh
sh agy-auth-installer.sh
```

The installer supports Linux x86_64, verifies the release archive with SHA-256, and installs to
`~/.local/bin`. Override the destination with `AGY_AUTH_INSTALL_DIR`.

Build-from-source fallback:

```bash
cargo install --locked --git https://github.com/ensp1re/agy-auth \
  --tag v0.2.0-rc.1 agy-auth-cli
```

## Security boundaries

- Official `agy` owns OAuth login, token refresh, model requests, and policy enforcement.
- `agy-auth` does not call private Google model, quota, usage, or entitlement APIs.
- Account selection is manual; automatic fallback and rotation are excluded.
- Full emails are masked before project-owned metadata persistence.
- Credential replacement is version-gated, bounded, permission-checked, atomic, and reversible.
